Anchor Tag

Anchor tag < a > defines a hyperlink.
tag is used to make any image or text, a hyperlink.
Attributes of Anchor tag are:
href:href stands for Hyperlink Reference. It specifies the URL(Uniform Resource Locator) of page the link goes to.
Name:It specifies the name of the Anchor.
Target:It specifies where the link will open. Its values are: _blank, _parent, _top, _self.
